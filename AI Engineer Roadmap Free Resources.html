The AI Engineer roadmap, with one free resource that actually earns its place at every stage

roadmap.sh gives you the map. This guide gives you the single most useful free resource for each stage on it — official docs, university courses, free books and open repos only, never a free trial or a paywalled course dressed up as free — plus one hands-on project per stage that proves you learned it, designed to cost $0. Where a pick's free status could not be fully verified, the card says so instead of promising $0.

The one thing to know before you start

This roadmap is not a from-zero curriculum. It assumes you already work as a developer — its first box literally says pick one of Frontend, Backend or Full-Stack. Programming, maths, ML fundamentals, deep learning, fine-tuning and deployment are not stages on the page. So this guide covers every roadmap.sh stage in order, and adds five clearly labelled supplementary stages (S1–S5) for the foundations the roadmap skips but beginners and employers still expect.

How every project here stays at $0

Free learning is not the same as free inference. Reading docs and running open models locally costs nothing; calling hosted frontier APIs is billed per token. Every project below is built around that distinction.

Always free — the $0 stack

  • Local models via Ollama or small open models from Hugging Face
  • Local vector stores — Chroma runs in-process, no server, no account
  • Local embeddings with Sentence Transformers
  • Official docs, GitHub course repos and university courses

Not free — flagged, never hidden

Hosted API calls (OpenAI, Claude, Gemini, OpenRouter) are billed per token, and LLM-as-judge evaluation multiplies that cost. Where a popular resource is only partly free — DeepLearning.AI labs behind Pro, freemium observability tools, Ollama Cloud — the stage card says so in its free catch.

Pre-requisites — arrive as a developer

On the roadmap: Frontend, Backend, or Full-Stack — pick one. In practice this means Python plus software foundations; if you already ship web apps, skip to Stage 1.

Best free resource
CS50's Introduction to Programming with Python — Harvard
Course · video + problem setscs50.harvard.edu/python

Why this pick: the most complete free Python course for a beginner — functions, exceptions, libraries, unit tests, file I/O, regex and OOP, all with graded-style exercises. It is exactly the Python surface the later stages assume.

Free catch: learning is free; the edX verified certificate is paid (optional). A free CS50 certificate via Harvard's own site is reported by third parties — verify on the course page before relying on it. No account needed to read or watch via Harvard's site.

Build this — what “done” means

A Git repo with a tested Python CLI — argument parsing, file I/O, unit tests, README — plus a tiny API (see S5). It demonstrates you can write, test and version real Python, not just notebooks.

Common Terminology — learn the words by using them

On the roadmap: AI vs AGI · LLM · Inference · Training · Vector DBs · RAGs · Prompt Engineering · AI Agents · Pre-trained Models · Tokens · Context.

Best free resource
Hugging Face LLM Course
Course · interactive notebooks + texthuggingface.co/learn/nlp-course

Why this pick: its own page states it is “completely free and without ads”, and it defines the vocabulary by using it — Transformers, Datasets, Tokenizers, the Hub, fine-tuning and sharing a model. That beats any glossary.

How LLMs Work — tokens, context, sampling

On the roadmap: Tokens · Context · Sampling Parameters (Temperature, Top-K, Top-P, Repetition Penalties) · Context Window · Fine-tuning and Context Engineering as side concepts · Inference Engineering.

Best free resource
3Blue1Brown — Neural Networks series + Essence of Linear Algebra
Video · YouTubeyoutube.com/@3blue1brown

Why this pick: the clearest free visual explanation of what a neural network computes and how gradients and backpropagation work — the intuition that makes “temperature / top-p” and “training vs inference” click, without needing a maths degree first.

Free catch: no exercises and no certificate — it builds intuition only, so pair it with the Stage 2 and Stage 6 coding work. No YouTube account is required to watch.

Build this — what “done” means

A notebook that runs the same prompt at temperature 0, 0.7 and 1.5 on a local model and records how output randomness and repetition change, with a one-paragraph explanation per setting. Demonstrates sampling parameters are controls, not magic numbers.

Prompt Engineering

On the roadmap: Prompt Anatomy (Input Format, System Prompting, Role & Behaviour, Context, Constraints, Structured Output) · Techniques (Zero-Shot, Few-Shot, ReAct, CoT) · Model Interaction (Function Calling, Prompt Caching, Streaming Responses).

Best free resource
Anthropic — Prompt Engineering Interactive Tutorial
Interactive tutorial · notebooks + Google Sheets versiongithub.com/anthropics/prompt-eng-interactive-tutorial

Why this pick: 9 chapters with exercises and a playground, from the model maker itself, covering exactly the roadmap's techniques — structure, role, separating data from instructions, chain-of-thought. Free, with no paid tier for the tutorial itself, per multiple 2026 listings.

Free catch — flagged: no certificate, and whether the interactive version currently needs a Claude API key (and therefore paid calls) could not be confirmed from Anthropic's own page in this research. Prefer the Sheets / no-API path or a local model for a guaranteed $0 run. Techniques transfer across models, but examples are Claude-flavoured.

Build this — what “done” means

A versioned prompt library in Git for one task — each prompt with a system prompt, 0-shot vs few-shot variant, a structured-output schema, and before/after outputs on 5 fixed test inputs. Demonstrates you change one variable at a time and keep the evidence.

Context Engineering

On the roadmap: Context vs Prompt Engineering · Context Layer & Sources · MCP · Context Security & Evaluation · RAG & Dynamic Filters · Memory Systems · Context Compaction · Long-Context Processing · State & Historical Context · Multi-agent Context Sharing · Context Isolation · Context Failure Modes.

Best free resource
Anthropic — “Effective Context Engineering for AI Agents”
Article · engineering guide, ~20 min readanthropic.com/engineering

Why this pick: the source of the term's modern definition — the “smallest set of high-signal tokens” — covering the roadmap's exact techniques: system-prompt altitude, minimal non-overlapping tools, just-in-time retrieval, compaction, structured notes, sub-agents. No course to buy.

Free catch — flagged: article only, no exercises or certificate. The URL was quoted in a secondary summary of Anthropic's guide; if it moves, search Anthropic Engineering for the title.

Build this — what “done” means

Take a 20-turn conversation that breaks a naive agent (context overflow, lost instructions) and fix it with two techniques: (1) summarise-and-compact history, (2) move a large document behind a retrieval tool. Show token counts before and after. Demonstrates context is a finite attention budget, not free space.

Core spine · Lists are alternatives

AI Models — closed, open, self-hosted

On the roadmap: Types (Closed, Open Source, Self-Hosted) · Choosing the Right Model · Open models (Meta Llama, DeepSeek, Qwen, Gemma) · Platforms (Hugging Face Hub, Ollama, LM Studio, OpenRouter) · APIs & SDKs (OpenAI Responses, Claude Messages, Gemini, HF Inference, OpenAI-compatible APIs). You are not meant to learn all of them.

Best free resource
Ollama — official site + docs
Tool · docs, CLI + local APIollama.com

Why this pick: the fastest free way to do the roadmap's “self-hosted” branch — one command pulls and runs an open model locally, and its API is OpenAI-compatible, so code written against it transfers to hosted APIs later. Open-source (MIT), free for local use with no usage limits, per multiple 2026 guides.

Free catch: local use is free; Ollama Cloud is a separate paid offering — you don't need it. Hardware is the limit: a 7–8B model at 4-bit needs roughly 5 GB plus RAM for context, and large models won't run well on a small laptop. Hosted API calls are billed separately.

Build this — what “done” means

The same script answering via (a) a local Ollama model and (b) an OpenAI-compatible endpoint, with a short comparison: latency, cost ($0 local vs per-token hosted), quality on 5 questions, and when you'd pick each. Demonstrates model choice is a cost / quality / latency trade-off, not brand loyalty.

Core spine · Pick one database

Embeddings & Vector Databases

On the roadmap: What Embeddings Are · Use Cases (Semantic Search, Classification, Recommendations, Anomaly Detection) · Embedding Models (OpenAI, Gemini, Cohere vs Sentence Transformers, HF models, Jina) · Vector DB purpose, Indexing, Similarity Search · “Popular Vector DBs (pick one)”: Chroma, Pinecone, Weaviate, FAISS, LanceDB, Qdrant, Supabase, MongoDB Atlas.

Best free resource
Microsoft — Generative AI for Beginners, search & embeddings lessons
Course · open repo lessons + codegithub.com/microsoft/generative-ai-for-beginners

Why this pick: it teaches embeddings as a search system — embed → store → retrieve — not as a formula, and its code runs with local models so the lesson stays free. For the database itself, use Chroma: open-source (Apache-2.0), pip install chromadb, runs in-process with no server — the roadmap's simplest pick-one choice.

Free catch: repo lessons that use hosted embedding APIs would cost — use a local Sentence Transformers model instead. Chroma's hosted Cloud features are paid / Cloud-only per a 2026 review; the local library is what this stage uses.

Build this — what “done” means

Semantic search over ~200 of your own documents (notes, docs, code): embed with a local model, store in Chroma, query 10 questions, and report top-3 hits with distances plus 3 failure cases (e.g. paraphrase vs keyword). Demonstrates similarity ≠ keyword match, and that metadata filtering matters.

Core spine · Frameworks are alternatives

RAGs — retrieval-augmented generation

On the roadmap: What RAG Is · Use Cases · RAG vs Fine-tuning · Implementing RAG (Chunking, Embedding, Vector Database, Retrieval, Generation) · Ways to implement (SDKs Directly, LangChain, LlamaIndex, Haystack, RAGFlow).

Best free resource
Microsoft — Generative AI for Beginners, RAG lessons — built first with SDKs directly
Course · open repo lessons + codegithub.com/microsoft/generative-ai-for-beginners

Why this pick: the repo's RAG lessons follow the roadmap's pipeline exactly — chunk → embed → retrieve → generate — and the roadmap itself lists “Using SDKs Directly” first. Building RAG once without a framework is what lets you debug LangChain or LlamaIndex later instead of cargo-culting them.

Free catch — flagged: hosted-model lessons cost; run it locally (Ollama + Chroma + Sentence Transformers) for $0. Not recommended as a main pick: DeepLearning.AI short courses are widely listed as “free”, but 2026 reports say videos are free to watch while hands-on labs and certificates sit behind Pro (~$25/month) — flagged here, not hidden.

Build this — what “done” means

A document Q&A app over a real corpus (a manual, a course's PDFs) with a chunk-size experiment (e.g. 256 vs 1024 tokens), a 20-question test set with expected answers, and scores for retrieval hit-rate and answer faithfulness — before any framework. Then re-implement retrieval with LangChain or LlamaIndex and show what changed. Demonstrates chunking and retrieval quality, not the framework, decide RAG quality.

Core spine · SDKs are alternatives

AI Agents

On the roadmap: Agent Use Cases · ReAct Prompting · Tools & Function Calling · Multi-agents · Building Agents (Manual Implementation, OpenAI AgentKit & Agent SDK, Claude Agent SDK, Vertex AI Agent Builder, Google ADK).

Best free resource
Hugging Face — AI Agents Course
Course · 5 units + capstonehuggingface.co/learn/agents-course

Why this pick: genuinely free, with free certificates — Fundamentals after Unit 1, Completion after a use-case assignment and a benchmarked final challenge, no deadline, per 2026 listings. It is framework-diverse (smolagents, LlamaIndex, LangGraph) and forces the roadmap's key discipline: build the same agent idea in more than one framework, ending in a benchmarked project instead of a watched video.

Free catch — flagged: cost is not zero by default. A 2026 review notes Hugging Face's Inference Providers docs list no included monthly inference credits for free users (PRO gets $2/month in compute credits). Plan assignments around local models or another provider where the exercise allows.

Build this — what “done” means

(1) A manual ReAct loop in ~100 lines, no framework — reason → tool call → observe — with a step limit and an approval gate for side-effect tools. (2) The same task rebuilt in one framework (LangGraph or smolagents). The README must list tools, memory strategy, failure modes seen (bad tool call, loop) and the guardrail for each. Demonstrates you understand the loop — and know when not to use an agent.

Core spine

Model Context Protocol (MCP)

On the roadmap: Core Components (MCP Host, Client, Server, Data Layer, Transport Layer) · Developing with MCP (Building a Server, Building a Client, Connect to Local Server, Connect to Remote Server).

Best free resource
MCP Python SDK — official documentation
Docs · open-source SDK (MIT)py.sdk.modelcontextprotocol.io

Why this pick: the official SDK docs are the shortest path from the roadmap's vocabulary — host / client / server, tools / resources / prompts, stdio vs Streamable HTTP — to a working server: a complete server takes ~15 lines, and mcp dev plus the Inspector let you test without writing a client.

Free catch: the SDK is free, but it is now v2 (2026-07-28 spec) with breaking changes from v1 — pin or migrate deliberately, and don't copy v1 examples blindly. Security: only connect to servers you trust, use least-privilege credentials, and require approval for sensitive actions.

Build this — what “done” means

An MCP server exposing 2 tools + 1 resource over stdio — e.g. search your Stage 7/8 corpus, read a file — inspected with the MCP Inspector, then consumed by two different clients (your Stage 9 agent + the Inspector). Demonstrates one server, many clients — the whole point of MCP — plus an approval step before any write/delete tool runs.

AI Safety and Ethics

On the roadmap: Prompt Injection Attacks · Security and Privacy Concerns · Bias and Fairness · Adversarial Testing · Content Moderation APIs · End-user IDs in prompts · Robust Prompt Engineering · Know Your Customers / Use Cases · Constraining Outputs and Inputs.

Best free resource
OWASP GenAI Security Project — LLM Top 10
Guide · free referencegenai.owasp.org

Why this pick: the industry reference the roadmap's topics map onto 1:1 — LLM01 Prompt Injection, sensitive-information disclosure, excessive agency, supply chain, data/model poisoning, unbounded consumption, misinformation, hidden-context exposure, vector/embedding weaknesses, improper output handling.

Free catch — flagged: the official OWASP URL was quoted in a secondary page and was not opened live in this research — verify the current edition on the site before citing a rank number. The 2026 edition reordered several items (Excessive Agency promoted to #3); do not copy 2025 numbers into 2026 work. Microsoft's GenAI security lessons are a free, fully-verified fallback.

Build this — what “done” means

An adversarial test pack for your Stage 8/9 app: at least 10 attacks — direct injection, indirect injection hidden in a retrieved document, prompt-leak attempt, excessive-agency attempt, PII exfiltration attempt — each with expected vs actual behaviour, the fix (input/output constraints, per-user retrieval authorisation, human gate for writes), and a re-test. Demonstrates safety is tested, not asserted.

Core spine · Tools are alternatives

Evaluation & Observability

On the roadmap: LLM Observability (Tracing & Logging, Cost/Latency Monitoring, Production Monitoring; tools: LangSmith, Langfuse, Helicone, Arize AI) · LLM Evaluations · Evaluation Types (Deterministic, Model-Based, Human Evals, Metrics) · Regression Testing · Evaluation Tools (DeepEval, RAGAS). Roadmap.sh spells this node “Observabiity”.

Best free resource
RAGAS — official documentation
Docs · open-source library (Apache-2.0)docs.ragas.io

Why this pick: RAGAS is the roadmap-named tool that directly measures what Stage 8/9 projects need — faithfulness, context precision/recall, response relevancy — and supports synthetic test-data generation. It turns “it feels better” into a number you can regression-test, and it runs locally for free.

Free catch — flagged: the library is free, but LLM-based metrics still need a judge model — use a local model or budget for hosted judge calls. A 2026 comparison notes RAGAS moved to a new GitHub home (vibrantlabsai/ragas) and was last updated February 2026 — check activity before building a long-term dependency on it. LangSmith / Langfuse / Helicone / Arize all have free tiers but are freemium: start with plain logging + RAGAS.

Build this — what “done” means

An eval suite for your RAG or agent: a fixed question set (≥30, drawn from real failures, not just happy paths), deterministic checks (format, citations present, no refusal on valid questions) plus RAGAS-style metrics, run before and after one change, with a regression report — what improved, what regressed, and the cost/latency per query. This is the skill employers cite as the separator.

Other AI Applications — multimodal & dev tools

On the roadmap: Multimodal AI (Image Understanding/Generation, Video Understanding, Audio Processing, Text-to-Speech, Speech-to-Text; APIs incl. OpenAI Vision, DALL-E, NanoBanana, Whisper, HF models) · Development Tools / AI-Assisted Coding (Claude Code, Gemini, Codex, Cursor, OpenCode, Replit, Vibe Coding). Do not learn every tool.

Best free resource
Microsoft — Generative AI for Beginners, image & audio lessons + Hugging Face Hub models

Plus a “vibe-coding” audit: one feature built with an AI coding tool, with a written review of every generated diff — what you accepted, rejected, and why.

Fine-tuning — SFT, LoRA / QLoRA, and when not to

Why it's here: roadmap.sh has no fine-tuning stage — only a side concept and a “RAG vs Fine-tuning” node. Learn the order first: prompting → RAG → fine-tuning, and do this stage after Stage 8.

Best free resource
Hugging Face — PEFT tutorial + TRL PEFT integration docs
Docs · official tutorialshuggingface.co/docs/peft · /docs/trl

Why this pick: official docs for the standard free stack (Transformers + PEFT + TRL): LoRA configs, trainable-parameter counts, QLoRA with bitsandbytes, and SFT examples on small models (e.g. Qwen 0.5B) that can actually run on limited hardware.

Free catch: the libraries are free; compute is the cost — use a ≤1B model and/or a free Kaggle/Colab GPU, and expect time limits. Some gated models (e.g. Llama) need a Hub account plus licence acceptance.

Build this — what “done” means

A LoRA fine-tune of a small open model on ~200–500 of your own instruction examples, evaluated against the base model on a held-out set with your Stage 12 suite — plus a written decision: did fine-tuning beat RAG/prompting here, and why? Demonstrates you fine-tune for a measured reason, not by default.

Docs · tutorialfastapi.tiangolo.com

What roadmap.sh misses, glosses over, or has aged

The roadmap page's header calls itself a guide “to becoming an AI Engineer in 2026” (published 2025-05-14, updated 2026-10-16). Read it with these gaps in mind.

1It teaches no foundations

No Python, maths, ML, deep-learning, NLP or deployment spine. A beginner following only this page hits Stage 7 without the prerequisites to understand it — hence S1–S5.

2No fine-tuning stage

Fine-tuning is a side concept and a comparison node. In 2026 practice, LoRA/QLoRA + SFT/DPO with PEFT/TRL is a standard, cheap skill — and when to fine-tune vs RAG vs prompt is an interview topic in itself (S4).

3No deployment / MLOps

No FastAPI, Docker, CI/CD, model serving, cost management or cloud deployment — despite employers listing exactly those (S5 + Stage 12 monitoring).

4No data engineering

Chunking is covered; ingestion, cleaning, deduplication, PII handling, dataset versioning and evaluation-data curation are not — yet they decide RAG quality more than the framework choice.

5Observability tools are freemium

LangSmith, Langfuse, Helicone and Arize AI all have free tiers with paid retention and features. The roadmap doesn't say that — start with local logging + RAGAS and add a hosted tracer deliberately.

6Model & API names age fast

The page still names “OpenAI (GPT, o-series)”, the DALL-E API and NanoBanana API, and agent SDKs since renamed or reorganised. Learn the pattern — API + SDK + local alternative — and check the provider's current docs before building.

7MCP has moved on

Introduced by Anthropic in November 2024; secondary sources in this research report it was donated to the Linux Foundation's Agentic AI Foundation in December 2025, and the Python SDK is now v2 on the 2026-07-28 spec. Don't learn MCP from v1 examples alone — and not every tool needs an MCP server; a direct function call is simpler for a single-purpose script.

8Safety numbering has moved

OWASP's LLM Top 10 was reordered in its 2026 edition — Excessive Agency up to #3, System Prompt Leakage broadened to Hidden Context Exposure. Don't reuse 2025 rank numbers.

9“Vibe coding” without review discipline

AI coding tools are listed as a stage; the employable skill is reviewing generated code, testing it and owning the diff — which is why Stage 13's project includes a written diff audit.

10Context engineering is now first-class

Anthropic's 2025 framing — compaction, sub-agents, just-in-time retrieval, context rot — postdates the original roadmap and is now central to agent work, hence its own Stage 5 here.

11Running costs are invisible

Nothing on the page warns that hosted models bill per token, that LLM-judge evals multiply cost, or that free tiers change (e.g. Hugging Face free-user inference credits). Budget every project in tokens + dollars, not just accuracy.

12Sponsored content sits on the page

The Scrimba “20% off” box on roadmap.sh is advertising, not a stage — and Scrimba's path is paid, so it is excluded from this free guide. The page also shows no published colour legend, so no claim is made here about what node colours mean beyond the text markers quoted.

Free-status flags — what could not be fully verified

Roadmap structure was verified live on 2026-10-28. Resource free status is from each resource's own listing or search-index description unless flagged below. These are stated plainly rather than smoothed over.

Anthropic Prompt Tutorial (Stage 4): described as free with no paid tier in multiple 2026 listings, but whether its live playground currently needs a Claude API key could not be confirmed from Anthropic's own page. Use the Sheets/offline path or a local model for a guaranteed $0 run.

OWASP GenAI (Stage 11): the URL was quoted in a secondary page; the live OWASP page was not opened in this research, and the 2026 reordering is reported by secondary guides. Verify the current edition on genai.owasp.org before citing a rank.

Anthropic Context Engineering article (Stage 5): URL as quoted in a secondary summary of Anthropic's guide. If it 404s, search Anthropic Engineering for the title.

DeepLearning.AI short courses: repeatedly marketed as “free”, but 2026 reports indicate videos are free to watch while labs and certificates require Pro (~$25/month billed annually). Not used as a main pick for that reason — it appears only as a Stage 8 warning.

Hugging Face inference credits (Stage 9): a 2026 review states free users get no included monthly inference credits (PRO: $2/month). Don't plan course assignments around an old free-credit allowance.

RAGAS (Stage 12): open-source (Apache-2.0), but a 2026 comparison notes a new GitHub home and a February 2026 last update — check activity before adopting it long-term. LLM-judge costs are separate.

CS50 certificate (Stage 0): learning is free and edX's verified certificate is paid; the free Harvard certificate path is reported by third parties, not confirmed on Harvard's own page in this research. Also open: exact current pricing and free-tier limits for hosted APIs, observability tools, Pinecone, coding assistants and Kaggle/Colab GPU quotas change frequently and were not re-verified on each provider's pricing page — check at time of use.
